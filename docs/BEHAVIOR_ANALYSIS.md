# 通用行为影响分析

分析依次回答：变化了什么、谁依赖它、依赖什么假设、什么条件能触发不匹配。结果是待确认候选，不是业务正确性证明。程序不执行项目代码、不连接数据库或 Redis、不调用模型。

## 事实与执行范围

JDK 8 AST 在原方法记录的 `behavior` 字段中提供参数、字段、分支、赋值、实参、返回和显式异常，保留 `scan_tree` 的三元返回接口。Python 有界解释器维护空值、常量、条件事实和来源；分别分析 BASE、HEAD，比较新增路径问题，再扩展到 javac 绑定的直接调用方。

支持顺序、if/else、短路、三元表达式、switch、提前返回、明确类型匹配的 catch 和 finally。finally 的显式返回/抛出覆盖原退出。循环、复杂表达式、switch 落空执行、未知异常匹配、动态调用会保留未知。每方法最多 256 个状态；单源码 500 KB、全部源码 20 MB、4000 文件、最多 10000 候选。截断有独立缺口，不得解释为安全。

方法内校验对参数及简单别名有效；赋值撤销旧值约束，未知调用撤销字段内容保证。整数除法与浮点除法分开；数组要求包括非空、非负及小于长度。跨方法传播限直接一跳，同名或同参数个数不足以进行语义传播。跨服务协议关系仍使用现有补证流程；首版行为解释器不模拟 RPC 执行。

## 三类候选

| 类别 | 触发依据 | 不应推断的结论 |
| --- | --- | --- |
| PRECONDITION | 新增或扩大路径上的非空、下标、整数非零要求，且支持范围内的校验未排除该路径 | 未识别校验不等于没有校验；方法参数可能在其他层已受约束 |
| RESULT_HANDLING | 新可空结果在调用方被使用，或有明确失败语义的结果未处理并继续执行/副作用 | 任意 boolean/数字/名为 success 的字段不是天然成功失败标记 |
| PERSISTENCE_COMPATIBILITY | 已关联资源的显式写入字段/值与读取范围、switch 分支或解引用要求不匹配 | 同名资源不等于同实例；序列化未知时不证明存储格式不兼容 |

资源适配器只提取框架事实。Redis 首版要求明确字面量键，动态前缀只保留原资源候选及缺口；支持显式字段/构造参数和默认值。SQL 支持简单 UPDATE/INSERT/SELECT、字面量与 MyBatis 参数、显式 resultMap；复杂投影、动态结构和隐式 ORM 不作完整推断。SQL WHERE 的取值限制表示“查询可能排除新值”，不代表查询语法错误。

版本组合分别为新版写/当前消费者、旧版可能写/新版读、新版写/旧版读；最后一种仅在消费者具有固定 BASE 时产生。实际写入方和读取方的 SHA 独立保留，不把跨版本兼容对照拼成调用链。读取端没有回退且旧形态缺少字段时，只提出“若反序列化缺失字段为空”的条件候选。

## 可选语义声明

沿用 `--project-registry projects.json`。`projects` 可以为空；语义配置对本次固定项目范围生效：

```json
{
  "projects": [],
  "analysis_semantics": {
    "results": [
      {
        "method": "com.example.Payment#submit(java.lang.String)",
        "failure_values": [false],
        "success_values": [true]
      },
      {
        "type": "com.example.Result",
        "member": "accepted",
        "failure_values": [false],
        "success_values": [true]
      }
    ],
    "effects": [
      {
        "method": "com.example.EventPublisher#publish(java.lang.String)",
        "operation": "MQ_SEND",
        "resource_argument": 0
      }
    ]
  }
}
```

结果规则使用 `method` 或完整 `type` 二选一，类型规则必须提供成员；取值仅接受 JSON 字符串、整数、布尔和 null，成功/失败集合不能重叠。源码能提取具体结果时优先对照源码；冲突记为缺口。缺失方法实现时的映射取值是声明的可能性，标记未知，不能当成真实执行结果。

副作用 operation 支持 DATABASE_WRITE、REDIS_WRITE、MQ_SEND，参数位置从零开始，绑定须为完整方法签名。首版不执行表达式、脚本或名称相似度推断，不验证事务提交、回滚与生产发送结果。

## 产物与复核

`behavior_impact_latest.json` 保存独立 B-* 候选、D-* 引用、双方版本、来源位置、触发路径、假设、可能影响及缺口。候选编号不含审核分组；规则、预算、语义映射、SHA 和 classpath 参与事实指纹。统一覆盖状态区分 COMPLETE、PARTIAL、FAILED、NOT_EXECUTED、UNKNOWN。

HTML 按方法或资源链汇总；同一资源候选可附带行为证据，明细保留原始编号。证据强度和输入影响分开记录：首版未完成新的输入传播时使用 MEDIUM，不能当作严重性评级。通用缺口在覆盖区显示。

`behavior_review_latest.json` 将事实映射到审核单元，重新分组只改变归属，拆分时只匹配确切 HEAD 范围。BASE 侧证据不能猜成 HEAD 侧范围。行为问题进入现有问题包和判断失效流程；语义映射或相关事实变化触发待重审。行为阶段尚无产物时覆盖为 UNKNOWN，不能显示为检查通过。

## 正确性规则与刷新边界

Java 扫描规则 `java-scopes-v2` 按标准 Maven `src/main/java`、`src/test/java` 或源码包目录识别编译范围，同一范围的源码共同交给 javac 归属。测试可引用本模块主源码，主源码不引用测试；其他模块源码不加入当前范围，跨模块仍需显式 JAR classpath。同名方法冲突记录诊断并禁用唯一绑定。分侧 `java_coverage` 与方法事实共同复用；无方法且存在 Java 源码、解析失败均保留缺口。缺少源码范围、当前行为 AST 或结构化诊断的方法事实会被拒绝。

行为 AST 规则为 `behavior-ast-v2`，解释规则为 `behavior-flow-v2`。数组初始化器从左到右求值，显式异常中断后续元素；构造方法在直接一跳范围内传播正常和异常退出，进入 catch/finally，异常路径不赋予已构造对象。整数常量携带类型，支持 int/long 加减乘、正负号、提升与整数窄化转换的 Java 溢出语义；无法确定的数值运算保留未知。非空、非零、上下界和数组长度关系只在全部依赖对象能映射到实参时传递；改变值的转换、重新赋值及不支持表达式不能沿用旧约束。

扫描及行为缓存指纹包含源码范围规则与 `BehaviorFacts.java`，只复用指纹一致的缓存。`coverage_latest.json` 汇总保存的状态、诊断、规则与截断，不启动扫描。当前版本作为初版，只处理当前格式；规则或必需字段不符合要求时拒绝读取或记录阶段失败，不进行旧格式转换。普通补证、语义补证、分组重算、判断导入和状态查询调用统一依赖刷新；时间戳、刷新次数和展示编号不作为事实变化。

JSON、阶段清单、Markdown 和 HTML 覆盖区使用同一汇总，行为扫描失败时允许生成报告，但批次仍为部分完成。HTML 保留为生成时快照；状态刷新仅生成最新派生状态，原始底账与审核日志保留。

验证使用真实 javac AST、固定 Git 版本及最小 Java/SQL 样例，覆盖正例、有效校验/回退反例和未知降级。运行项目原有 unittest 与编译检查，不能将这些测试称为生产环境验收。
